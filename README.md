## ⚡ Design System & Features
- **Palette**: Strict monochromatic black (`#000000`) and pure white (`#FFFFFF`) with subtle zinc accents.
- **Typography**: Space Grotesk exclusively, with `-1px` character spacing across all headlines.
- **Main Logo Displays**: Every portfolio card presents the brand's primary logo as the main visual cover.
- **Multi-Image Galleries**: In-page interactive modal gallery with thumbnail selection + dedicated standalone case study pages.
